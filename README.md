# Duel Dash 3D

Мобильный 3D-прототип для Android на Godot 4.3. Проект сделан как следующий шаг после Duel Dash 2P и не требует внешних 3D-моделей: мультяшные персонажи, арена и трасса создаются прямо кодом из простых 3D-примитивов.

## Что уже есть

- 3D-драка один на один.
- 3D-гонка с препятствиями и ускорением.
- 6 бойцов разных цветов.
- Процедурная мультяшная графика и анимация рук/ног.
- Удары, здоровье, отбрасывание и экран результата.
- Игра против бота без второго телефона.
- Wi-Fi LAN: один телефон создаёт хост, второй подключается по локальному IP.
- Сенсорные кнопки для Android и клавиатура для проверки на ПК.
- Простые процедурные звуки без внешних аудиофайлов.
- Режим экономной графики для слабых телефонов.
- GitHub Actions, который собирает debug APK.

## Управление

### Драка
На телефоне используйте стрелки слева и кнопку `УДАР` справа. На ПК: WASD/стрелки и Space/F.

### Гонка
На телефоне используйте стрелки влево/вправо и `BOOST`. На ПК: A/D или стрелки, Space/E для ускорения.

## Игра без второго телефона

На главном экране нажмите `ИГРАТЬ С БОТОМ`, затем выберите 3D-драку или 3D-гонку. Сеть не требуется.

## Игра на двух телефонах по Wi-Fi

1. Подключите оба телефона к одной Wi-Fi сети. Также можно включить точку доступа на одном телефоне и подключить к ней второй.
2. На первом телефоне откройте `ИГРА ПО WI-FI` и нажмите `СОЗДАТЬ ХОСТ`.
3. Приложение покажет локальный IP и порт 24567.
4. На втором телефоне введите IP первого телефона и нажмите `ПОДКЛЮЧИТЬСЯ`.
5. После подключения хост выбирает `3D ДРАКА` или `3D ГОНКА`.

Сетевой режим этого прототипа синхронизирует позиции и игровые действия через Godot ENet. Он рассчитан на локальную сеть и двух игроков.

## Сборка APK через GitHub

Загрузите содержимое проекта в GitHub. Workflow `.github/workflows/android-apk.yml` запустится при push или вручную через Actions -> Build Godot Android APK -> Run workflow.

После успешного запуска скачайте artifact `DuelDash3D-debug-apk`. Внутри будет `DuelDash3D-debug.apk`.

Workflow использует контейнер `barichello/godot-ci:4.3`, в котором настроены Godot, экспортные шаблоны, Java и Android SDK.

## Локальный запуск

Установите Godot 4.3, откройте `project.godot` и нажмите F6/F5. Для Android добавьте Android export preset при необходимости или используйте уже включённый `export_presets.cfg`.

## Статус

Это играбельный технический прототип, а не финальная коммерческая версия. Следующие разумные шаги: импорт настоящих GLB-моделей, скелетные анимации, полноценные частицы/VFX, музыка, матчмейкинг, улучшенная компенсация задержки и дополнительные 3D-мини-игры.
